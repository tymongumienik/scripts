# justjoinit-scraper

Script for fetching job offers data via scraping the justjoin.it website.  
It provides an interactive CLI for filtering offers by city, experience, salary, etc., and presents the results in a local HTML page.

## Requirements

- Python >=3.12
- [uv](https://github.com/astral-sh/uv)

## Installation

This project uses `uv` for dependency management.

```bash
uv sync
```

## Usage

```bash
uv run main.py
```
